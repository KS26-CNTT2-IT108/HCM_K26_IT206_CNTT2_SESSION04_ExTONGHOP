Kết quả thực thi qua chuỗi Prompt:
Bước 1 (Error Handling): Xác nhận cú pháp hợp lệ, chuyển tiếp sanitized_code.
Bước 2 (Chain-of-Thought): Phát hiện nguy cơ sập chương trình nếu truyền danh sách rỗng (lst = []).
Bước 3 (Actionable Output):
Điểm: 70/100 (Trừ vì thiếu xử lý ngoại lệ).

Mã nguồn Refactor chuẩn hóa:
Python
def tinh_trung_binh(lst):
    """Tính trung bình cộng an toàn, chống lỗi ZeroDivisionError."""
    if not lst:
        return 0.0
    return sum(lst) / len(lst)
